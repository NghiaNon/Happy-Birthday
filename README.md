# 🎂 Chúc Mừng Sinh Nhật Em Bé

Một trang web chúc mừng sinh nhật ngọt ngào, lãng mạn và đầy ắp những điều bất ngờ dành riêng cho người yêu thương nhất.

## ✨ Điểm nổi bật
- 💌 **Hành trình cảm xúc theo từng phân cảnh (Scenes):** Tương tác từng bước từ lời chào, dỗi hờn đáng yêu, dỗ dành, xoa đầu, ước nguyện cho đến món quà bất ngờ.
- 🎵 **Hộp nhạc Web Audio du dương:** Tự động phát âm thanh du dương, trong trẻo mà không phụ thuộc file nhạc ngoài.
- 💖 **Hiệu ứng phong phú:** Cơn mưa tim bay, vệt hạt con trỏ theo ngón tay/chuột, pháo hoa giấy chúc mừng.
- 📱 **Tương thích hoàn hảo (Responsive 100dvh):** Hiển thị trọn vẹn 1 khung hình trên cả điện thoại di động và máy tính, không cần cuộn trang.

## 🚀 Cách chạy dự án

### Mở trực tiếp
Mở file `index.html` bằng bất kỳ trình duyệt nào (Chrome, Edge, Firefox, Safari...).

### Hoặc chạy qua Localhost
```bash
# Sử dụng Python
python -m http.server 8080

# Hoặc sử dụng Node.js npx
npx serve
```
Sau đó truy cập: [http://localhost:8080](http://localhost:8080)
